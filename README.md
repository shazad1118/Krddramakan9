# KRDDramakan 🎬

ماڵپەڕی سەیرکردنی ڕاستەوخۆی دراما بە زمانی کوردی — بێ ڕیکلام، بە دیزاینی
وەک نێتفلیکس.

## پێکهاتەی پڕۆژە

```
KRDDramakan/
├── index.html      → پەڕەی سەرەکی (سەرەتا، وردەکاری دراما، گەڕان، ڕێکخستن،
│                      دەربارە، چوونەژوورەوەی ئەدمین، پانێڵی ئەدمین)
├── style.css        → هەموو دیزاینەکە (شێوازی نێتفلیکس)
├── script.js         → هەموو لۆجیکی ئەپەکە
├── server.py         → سێرڤەرێکی سادەی پایتۆن بۆ ڕاکردنی سایتەکە لۆکاڵی
└── json/
    ├── drama.json    → دراماکانی بنەڕەتی (بووکی تازە)
    └── admin.json    → زانیاری چوونەژوورەوەی ئەدمین
```

## چۆن ڕایبکەم؟

```
cd KRDDramakan
python3 server.py
```
پاشان بڕۆ بۆ: `http://localhost:8000`

(دەتوانیت پۆرتی جیاواز بەکاربهێنیت: `python3 server.py 5500`)

## زانیاری چوونەژوورەوەی ئەدمین (نموونەیی)

فایلی `json/admin.json`:
```json
{
  "username": "admin",
  "password": "admin123",
  "code": "7410"
}
```
لە ماڵپەڕەکە: ڕێکخستن ← بەشی ئەدمین ← ئەم سێ زانیارییە بنووسە.

> ✏️ پێش بڵاوکردنەوەی ڕاستەقینە، تکایە ئەم سێ خانەیە بگۆڕە بۆ
> ناوی بەکارهێنەر/وشەی نهێنی/کۆدی تایبەت بەخۆت.

## پانێڵی ئەدمین — چوار تاب

پاش چوونەژوورەوە، پانێڵی ئەدمین چوار بەشی هەیە:

### 1) درامای نوێ
خانەکان پڕبکەرەوە (ناو، ژانر، کورتە چیرۆک، لینکی پۆستەر، لینکی ئەڵقەی یەکەم)
و کرتە لەسەر «دروستکردنی دراما» بکە. دراماکە دەستبەجێ لەسەر سەرەتا
دەردەکەوێت.

### 2) زیادکردنی ئەڵقە
ئەم بەشە بۆ زیادکردنی ئەڵقەی نوێیە بۆ هەر درامایەکی هەیە (نوێ یان کۆن):
1. لە لیستی «بۆ کام دراما» ناوی درامایەکە هەڵبژێرە.
2. خۆکارانە ناونیشانی ئەڵقە پێشنیار دەکرێت (بۆ نموونە «بەشی 6»)؛
   دەتوانیت بیگۆڕیت.
3. لینکی سەیرکردنی ئەڵقەکە دابنێ.
4. کرتە لەسەر «زیادکردنی ئەڵقە» بکە — ئەڵقەکە دەستبەجێ زیاد دەبێت و
   لە لیستی خوارەوە بە ژمارە دەردەکەوێت. دەتوانیت بەردەوام بیت لە
   زیادکردنی چەندین ئەڵقە بۆ هەمان دراما بەبێ دووبارە هەڵبژاردنەوەی.

### 3) بەڕێوەبردنی دراماکان
لیستی هەموو دراماکان (بنەڕەتی + زیادکراوی خۆت)، بۆ هەریەکێک:
- **گۆڕانکار (توگڵ)** بۆ بڵاوکردنەوە/شاردنەوە — کاتێک شاردرایەوە، ئەو
  دراما لای هیچ بینەرێک نایەت.
- **دووگمەی سڕینەوە** (تەنها بۆ دراماکانی خۆت) — دراماکە دەبات بۆ تابی
  «سڕینەوە». سڕینەوەی «تێکەڵی دراما» ئەو دراما ڕەش دەکاتەوە (سڕینەوەی
  نەرم) و لە خوارەوەی هەمان لیستدا بە شێوەی ڕەش/تاریک دەردەکەوێت — لای
  هیچ بینەرێک نامێنێت، بەڵام هەمیشەیی نییە.

### 4) گەڕاندنەوە
لیستی دراما ڕەشکراوەکان (سڕدراوەکان)، دراما هەڵبژێرە و بڵێ چی بگەڕێتەوە:
- **دراما و ئەڵقەکانی** — دراما لەگەڵ هەموو ئەڵقەکانی وەک خۆیان دەگەڕێنەوە.
- **تەنها دراما** — تەنها دراماکە دەگەڕێتەوە بێ هیچ ئەڵقەیەک (ئەڵقە
  کۆنەکانی دەسڕدرێنەوە).
سڕینەوەی «ئەڵقەکان» یان «ئەڵقەیەک» لە تابی سڕینەوە هەمیشەیین و
ناگەڕێنەوە.

### 5) ڕێکخستنی ئەدمین
10 گۆڕانکاری (توگڵ) بۆ چالاک/ناچالاککردنی تایبەتمەندییەکانی سایتەکە:
هیرۆ، چیپی ژانر، گەڕان، گۆڕینی ڕووناکی، بەشی دەربارە، ژمارەی ئەڵقە
لەسەر کارت، کورتە چیرۆک لە وردەکاری، و ڕێگەدان بە زیادکردن/سڕینەوەی
دراما لەلایەن ئەدمینەوە. هەمووی دەگەڕێنرێتەوە بۆ بنەڕەت بە دووگمەی
«گەڕاندنەوە بۆ بنەڕەت».

### تێبینی گرنگ دەربارەی هەڵگرتنی داتا
ئەم ماڵپەڕە دوو شێوازی هەڵگرتنی داتای هەیە:

- **بە سێرڤەر (پێشنیارکراو):** کاتێک بە `python3 server.py` ڕایدەکەیت،
  هەر گۆڕانکارییەکی ئەدمین (زیادکردن/دەستکاریکردن/سڕینەوە/شاردنەوە) بە
  شێوەی خۆکار دەنێردرێت بۆ سێرڤەر و لە فایلی `json/drama.json` دا
  پاشەکەوت دەکرێت — واتە **لای هەموو بەکارهێنەرانی سایتەکە دیار دەبێت**،
  نەک تەنها لەناو وێبگەڕی خۆت. پشتگیری (backup) خۆکاری هەیە:
  `json/drama.backup.json`.
- **localStorage (بەکارهاتنی خۆکاری):** ئەگەر سایتەکە بەبێ سێرڤەر بکرێتەوە
  (بۆ نموونە فایلی HTML ڕاستەوخۆ، یان هۆستکردنی ستاتیکی)، گۆڕانکارییەکان
  وەک جاران تەنها لە وێبگەڕی خۆت هەڵدەگیرێن — هیچ کێشەیەک دروست نابێت،
  تەنها بڵاوکردنەوەی خۆکار بۆ هەموو بەکارهێنەران کارناکات.

### لینکی ڤیدیۆ — هەموو جۆرەکان کاردەکات
لە خانەی «لینکی ئەڵقە» دەتوانیت هەر جۆرە لینکێک دابنێیت و پلەیەرەکە
خۆکارانە جۆرەکەی دەناسێتەوە: **یوتیوب، ڤیمیۆ، گووگڵ درایڤ، دەیلی‌ماشن،
فەیسبووک،** یان لینکی ڕاستەوخۆی فایل (mp4/m3u8/webm/...).

## زیادکردنی دەستی دراما بۆ json/drama.json

دەتوانیت بەبێ ئەدمین‌پانێڵ، دراما زیاد بکەیت بە دەستکاریکردنی ڕاستەوخۆی
فایلی `json/drama.json`:

```json
{
  "id": "d002",
  "name": "ناوی دراماکە",
  "genre": "کوردی",
  "poster": "لینکی وێنەی پۆستەر",
  "backdrop": "لینکی وێنەی گەورە (بۆ هیرۆ/وردەکاری)",
  "desc": "کورتە چیرۆکی دراماکە",
  "featured": false,
  "episodes": [
    { "title": "بەشی 1", "link": "لینکی ڕاستەوخۆی بەشی یەکەم" },
    { "title": "بەشی 2", "link": "لینکی ڕاستەوخۆی بەشی دووەم" }
  ]
}
```
- `"featured": true` بکە ئەگەر دەتەوێت ئەو دراما لە بەشی هیرۆی سەرەوەی
  ماڵپەڕ دیاربکرێت.

## تایبەتمەندییەکان

- ✅ تەنها دراما — هیچ فیلمێک نییە
- ✅ بەشەکان (episodes) بە تەواوی لە یەکتر جیاکراونەتەوە بە دیزاینێکی جوان
- ✅ دیزاینی وەک نێتفلیکس (ڕەشی قووڵ + سووری تایبەت)
- ✅ هیرۆیەکی گەورە بۆ دراماکە سەرەکییەکە لەسەر سەرەتا
- ✅ فلتەرکردن بەپێی ژانر و گەڕان بە ناو
- ✅ ڕێکخستنی ڕووناکی: سپی/ڕەش
- ✅ بەشی ئەدمین: چوونەژوورەوە بە ناو/پاسۆرد/کۆد، زیادکردنی دراما،
  سڕینەوەی دراما، هەموو داتاکان دەمێننەوە
- ✅ تەواو ڕێسپۆنسیڤ — لەسەر مۆبایل و دیسکتۆپ

## 📱 PWA — زیادکردنی بۆ هۆم‌سکرین (iPhone/Android)

### چۆن ئایکۆنەکەی خۆت دابنێی

فۆڵدەری `icons/` لە ناو پرۆژەکەدایە. ئەم فایلانە دابنێ:

| فایل | قەبارە | بۆ چی |
|------|--------|-------|
| `icons/icon-192.png` | 192×192 px | Android / Chrome |
| `icons/icon-512.png` | 512×512 px | Android Splash Screen |
| `icons/apple-touch-icon.png` | 180×180 px | iPhone / iPad Home Screen |

> **تێبینی:** PNG بێت، پشتزمینی ڕەش یان جوان بێت. گۆشەی دۆزەری (rounded) ئاپڵ خۆی دەکاتەوە.

### چۆن بۆ ئایفۆن زیاد بکەی
1. سایتەکە بکەرەوە بە **Safari**
2. دوگمەی Share (چوارگۆشەی تیری سەرەوە) بکە
3. **Add to Home Screen** هەڵبژێرە
4. ناوەکە بنووسە، **Add** بکە
5. ئایکۆنەکەت لەسەر هۆم‌سکرین دەردەکەوێت ✅
